
# Документация библиотеки Geometric Lib в Лабораторной 2
## Общее описание библиотеки
`Geometric_lib` содержит в себе функции для вычисления площади и периметра квадрата и круга
## Список функций
### Circle.py
* `area(r)` считает площадь круга
Функция принимает парметр r (int, float) и по формуле math.pi\*r\*r вычисляет площадь круга.
`Пример:`
Входные данные: r = 3
Вызов функции: area(3)
Вывод: 28.274333882308138         
- `perimeter(r)` считает длину окружности
Функция принимает парметр r (int, float) и по формуле math.pi\*2\*r вычисляет длину окружности.
`Пример:`
Входные данные: r = 3
Вызов функции: perimeter(3)
Вывод: 18.84955592153876
### Square.py
* `area(a)` считает площадь квадрата
Функция принимает парметр a (int, float) и по формуле a\*a вычисляет площадь квадрата.
`Пример:`
Входные данные: a = 16
Вызов функции: area(16)
Вывод: 256
- `perimeter(a)` считает периметр квадрата 
Функция принимает парметр a (int, float) и по формуле a\*4 вычисляет периметр квадрата.
Входные данные: a = 16
Вызов функции: perimeter(16)
Вывод: 64
