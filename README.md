
# Geometric Lib
> Библиотека на Python , предназначенная для вычисления плоади и периметра квадрата и круга 
## О проекте
Этот проект - лабораторная работа 2 по курсу "Инстументальные средства разработки ПО". Библиотека содержит набор функций для расчета параметров круга и квадрата. 
# Структура проекта
### Корневые файлы
*   **`README.md`** — главный файл документации, содержащий общее описание проекта, инструкцию по запуску и ссылки на подробную документацию.
*   **`circle.py`** — модуль, содержащий функции `area(r)` и `perimeter(r)` для вычислений параметров круга.
*   **`square.py`** — модуль, содержащий функции `area(a)` и `perimeter(a)` для вычислений параметров квадрата.
*   **`.gitignore`** — служебный файл, указывающий Git, какие файлы и папки не нужно отслеживать (например, системные файлы macOS `.DS_Store`).

### Папка `docs/`
*   **`README.md`** — подробная документация проекта. Включает в себя:
    *   Общее описание решения.
    *   Детальное описание каждой функции с параметрами и примерами вызова.
    *   Историю изменения проекта с хешами коммитов.
